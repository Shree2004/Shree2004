<summary><b>◆ Digital Wallet — Transaction Management System</b></summary>

<br/>

A secure, enterprise-grade digital wallet platform engineered for high-throughput financial transaction processing. Built with a domain-driven design approach, the system handles fund transfers, balance management, and transaction ledger operations with strong consistency guarantees and audit-ready logging.

The architecture enforces strict transactional integrity through Spring's `@Transactional` propagation model, preventing partial updates and race conditions in concurrent transfer scenarios. Security is layered through Spring Security with JWT-based session management and BCrypt password hashing.

|-----------|---------|
